## 🚀 Easy Setup Guide

1. Copy **`version.dll`** to `HTGame\Binaries\Win64\` (inside your game installation folder).
2. Place **`strikerv2.exe`** anywhere and run it as **Administrator** (blocks game telemetry/heartbeats and launches the game).
3. **IMPORTANT**: Make sure **DX11** is selected in your game launcher settings.
4. *Note: There is a **45-second delay** after clicking play before the menu injects. Do not panic!*
5. Extract **`NTEWaypoint.zip`** directly to your **C:\** drive so that the folder is exactly `C:\NTEWaypoint\`.
6. Press **`Insert`** to toggle the in-game menu.
